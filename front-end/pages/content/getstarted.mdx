# General Instructions for All Users

- If you have more than one group in the same study, enter each group in a row; the same study ID should be used for all of them.
- For all conversions except Between groups difference (p-value, CI, SE of difference), use the total number with all groups, while for Between groups difference conversions (p-value, CI, SE of difference), use Group 1 number and Group 2 number.
- For the "Group number" column, use the same group number for the same arm in all included studies (For ex: if you have intervention X present in five included studies, code it with the same code number [ex: 1] in front of all of them), in order to get the same arm from all studies arranged below each other, which facilitate the next step (copy & paste into the meta-analysis software)
- For the "Pre-post" column, code pre-treatment (baseline) with 0, and post-treatment with 1 and more (if you have more than follow-up period and you want to calculate the change after each period)
- In combination, use the same variable name (Case-Sensitive) for all groups you want to combine
